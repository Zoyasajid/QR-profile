# Qora — QR Profile Platform (prototype)

Front-end-only Next.js prototype: **one QR code → multiple profiles**.

Demo login: `alex@qora.demo` / `demo1234` (or any email + 6-character password).

## Run

```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js 15 (App Router), TypeScript, Tailwind CSS v4, Lucide icons, React state + `localStorage`.

No backend, payments, or real QR generation.
